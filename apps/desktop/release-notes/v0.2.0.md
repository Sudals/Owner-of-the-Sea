## 바다의 주인 v0.2.0

이름 하나로 시작하고, 기록은 서버에 저장돼요. 다른 PC에서는 이어하기 코드로 이어서 할 수 있어요.

### 새로 들어간 것
- **섬 마을**: 시장(물고기 팔기), 상점, 연료, 수리, 덕배 할멈의 지렁이(하루 20개), 도감
- **경제**: 섬마다 다른 시세와 오늘의 특가, 신선도(1분에 1%), 한 섬에 몰아 팔면 떨어지는 수요
- **미끼**: 지렁이·새우·루어 등 — 입질이 오면 1개 쓰고, 입질 전에 거두면 그대로
- **쓰레기**: 비닐봉지·페트병·깡통·장화·그물 뭉치·폐타이어·기름 드럼 — 섬에서 처리하면 몇 G
- **창고 · 장비 화면 (I)**: 창고 물고기, 장비 레벨과 다음 레벨을 파는 곳, 소지품
- **소모품**: 수리 키트(바다에서 R), 소금 절임, 얼음 덩이
- **손맛 연출**: 부딪히면 파편·화면 흔들림·빨간 깜빡임, 낚시 물보라, 줄 끊김 "툭!", 희귀어 반짝임
- 섬 배경 3종(물장터·소금꽃섬·마을), 해도 정리(부두를 한 줄로, 떠 있는 상자처럼 보이던 그림 정리)

### 고친 것
- 섬에 정박하고 나갔다가 이어하면 바다 위에서 시작하던 문제
- 글자가 상자 밖으로 넘치던 곳들

### 설치
- `OwnerOfTheSea-Setup-0.2.0.exe` — 설치판 (설치 폴더 선택 가능)
- `OwnerOfTheSea-0.2.0-portable.exe` — 설치 없이 바로 실행
- 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen이 경고할 수 있어요 → "추가 정보" → "실행"
