## 바다의 주인 v0.3.0

이름 하나로 시작하고, 기록은 서버에 저장돼요. 다른 PC에서는 이어하기 코드로 이어서 할 수 있어요.

### 새로 들어간 것
- **걸어 다니는 마을**: 섬에 배를 대고 "마을 들어가기"를 고르면 마을을 위에서 내려다보며 걸어 다녀요(방향키·WASD, 또는 클릭한 곳으로 걸어가기).
  - 시장·상점·주유기·배 수리·덕배 할멈의 지렁이는 이제 마을 안의 사람과 가게를 찾아가야 쓸 수 있어요(가까이 가서 Space).
  - 빨간등대·물장터·소금꽃섬·종탑섬 마을. 할머니, 말순, 강노인, 아이 바다 같은 마을 사람들이 있고, 밤에는 가로등이 켜져요.
- **경제**: 섬마다 다른 시세와 오늘의 특가, 신선도, 한 섬에 몰아 팔면 떨어지는 수요
- **미끼**: 입질이 오면 1개 쓰고, 입질 전에 거두면 그대로
- **쓰레기**: 비닐봉지·페트병·깡통·장화·그물 뭉치·폐타이어·기름 드럼 — 마을에서 처리하면 몇 G
- **창고 · 장비 화면 (I)**: 창고 물고기, 장비와 다음 레벨을 파는 곳, 소지품 — 소금 절임·얼음 덩이도 여기서
- **수리 키트**: 바다에서 R
- **손맛 연출**: 부딪히면 파편·화면 흔들림·빨간 깜빡임, 낚시 물보라, 줄 끊김 "툭!", 희귀어 반짝임

### 고친 것
- 0.1.0 기록으로 0.2.0을 켜면 "Cannot read properties of undefined (reading 'length')"가 뜨던 문제
- 섬에 정박하고 나갔다가 이어하면 바다 위에서 시작하던 문제
- 바다 지도에 상자처럼 떠 보이던 부두·잠긴 마을 그림, 글자가 상자 밖으로 넘치던 곳들

### 설치
- `OwnerOfTheSea-Setup-0.3.0.exe` — 설치판 (설치 폴더 선택 가능)
- `OwnerOfTheSea-0.3.0-portable.exe` — 설치 없이 바로 실행
- 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen이 경고할 수 있어요 → "추가 정보" → "실행"
