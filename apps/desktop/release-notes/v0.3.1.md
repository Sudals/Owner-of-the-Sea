## 바다의 주인 v0.3.1

마을을 다시 그렸어요. 기록은 0.3.0과 그대로 이어져요.

### 마을이 달라졌어요
- **둥근 해안선**: 계단처럼 각지던 섬 가장자리가 둥글어졌고, 물가에는 얕은 물빛과 밀려왔다 빠지는 파도 거품이 생겼어요. 풀밭·모래·바위·길의 경계도 부드러워졌어요.
- **그림자**: 집과 나무, 좌판, 등대와 종탑에 그림자가 생겼어요.
- **진짜 뗏목 마을**: 물장터와 종탑섬이 여러 장의 뗏목과 통나무 뗏목으로 나뉘고, 판자 다리와 밧줄 난간으로 이어져요.
- **마을마다 다른 모습**: 할아버지의 낡은 집(판자로 막힌 문), 소금꽃섬의 소금 창고와 수레, 할멈의 텃밭과 빨랫줄, 우물·벤치·생선 말리는 대, 아이들의 공과 화분.
- **살아 있는 마을**: 굴뚝 연기, 하늘을 도는 갈매기(가까이 가면 날아올랐다가 다시 내려앉아요), 꽃밭의 나비, 출렁이는 나룻배. 마을 사람들은 두리번거리다 가까이 가면 돌아보고, 인사할 때 폴짝 뛰어요.
- 좌판 뒤의 아이들 얼굴이 보이고, 이름표는 한 번에 하나만 떠요.

### 설치
- `OwnerOfTheSea-Setup-0.3.1.exe` — 설치판
- `OwnerOfTheSea-0.3.1-portable.exe` — 설치 없이 바로 실행
- 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen이 경고할 수 있어요 → "추가 정보" → "실행"
