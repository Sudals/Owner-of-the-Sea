## 바다의 주인 v0.3.2

어떤 크기의 창에서도 화면이 꽉 차고, 낚시 손맛이 달라졌어요. 기록은 0.3.1과 그대로 이어져요.

### 화면
- **창을 꽉 채워요**: 창 크기를 어떻게 바꿔도 검은 띠 없이 게임이 꽉 차요. 비율이 안 맞아 남는 자리에는 게임 화면이 흐릿하게 깔려요.
- **설정 → 화면**: `꽉 차게`(기본, 어떤 크기든 채움) / `선명하게`(정수 배율만, 픽셀이 가장 또렷함) 중에서 고를 수 있어요.
- **바다와 마을은 더 넓게**: 울트라와이드(21:9·32:9)나 4:3 화면에서는 바다 지도와 마을이 화면 비율만큼 더 넓게 보여요. 상태창과 버튼은 화면 모서리에 붙어요.
- 640×360보다 작은 화면에서는 작게 줄어들고, 폰을 세로로 들면 "화면을 가로로 돌려 주세요"가 떠요.

### 낚시 — 텐션 유지 구간
- 텐션 게이지에 **초록 구간**이 생겼어요. 바늘이 구간 안에 있을 때만 물고기가 끌려오고 게이지가 차요.
  - 너무 느슨하면 물고기가 줄을 끌고 나가고, 너무 세면 버티기만 하다가 끝(빨간 부분)에 닿으면 줄이 끊어져요.
- **물고기가 셀수록 구간이 좁아요**: 일반 물고기는 넓고(약 35%), 전설·오염체는 좁아요(약 16%).
- 날뛰는 물고기는 구간이 위아래로 흔들리고, 날뛸 때 텐션이 확 튀어요. 물고기가 지치면 구간이 조금씩 넓어지고, 좋은 낚싯줄일수록 구간이 넓어요.

### 고친 것
- 비율이 다른 창에서 이름 입력칸이 어긋나던 문제
- 판매할 때 "+G" 효과가 상점 창에 가려지던 문제
- 큰 창에서 프레임이 떨어지던 문제

### 설치
- `OwnerOfTheSea-Setup-0.3.2.exe` — 설치판
- `OwnerOfTheSea-0.3.2-portable.exe` — 설치 없이 바로 실행
- 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen이 경고할 수 있어요 → "추가 정보" → "실행"
