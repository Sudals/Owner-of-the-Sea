## 바다의 주인 v0.3.3

물고기를 판 돈이 사라지던 버그를 고치고, 마을 상인들이 자기 가게 안에서 장사하게 된 업데이트예요. 기록은 0.3.2와 그대로 이어져요. **0.3.2 이하를 쓰고 있다면 꼭 업데이트해 주세요.**

### 고친 것
- **판매한 돈이 사라지던 문제**: 섬에 도착해 저장된 물고기를 시장에서 팔면, 시장 창을 닫고 저장할 때 판매가 취소되던 버그를 고쳤어요. 그동안은 골드가 판매 전으로 돌아가고 물고기도 함께 사라졌어요.
- 서버가 거래를 받아들이지 않으면 이제 화면에 "거래 N건은 서버에서 취소"라고 알려 줘요.

### 마을
- **상인은 가게 안에**: 덕배 할멈의 집과 소금 가게에 판매 창구가 생겼고, 주인이 창구 안에서 손님을 맞아요. 배 수리공들은 창고 안, 고치던 배 옆에 서 있어요. 소금 가게에는 정순 아주머니가 새로 왔어요.
- **카운터 앞 어디서나 거래**: 이제 가게 앞 딱 한 칸이 아니라 카운터 앞 어디에 서도 거래할 수 있어요. 가까이 가면 거래할 수 있는 자리가 보이고, 들어서면 노랗게 빛나요. 가게를 클릭하면 가장 가까운 자리로 걸어가요.
- **이름**: 마을 사람들에게 제 이름이 생겼어요 — 옥분 아주머니, 칠복 아저씨, 정순 아주머니, 바다, 별이 등. 이름표와 말풍선은 지붕 위에 떠요.

### 설치
- `OwnerOfTheSea-Setup-0.3.3.exe` — 설치판
- `OwnerOfTheSea-0.3.3-portable.exe` — 설치 없이 바로 실행
- 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen이 경고할 수 있어요 → "추가 정보" → "실행"
