# Credits — 바다의 주인

## Graphics

All sprites, tiles, backgrounds, UI and the app icon are original, generated from code in
`packages/sprites` (a shared 32-color palette → PNG sheets). No third-party art is used.

## Fonts

- **Galmuri** by Minseo Lee (quiple) — SIL Open Font License 1.1
  https://github.com/quiple/galmuri · npm `galmuri`
  The font is bundled with the game; its license file ships alongside it.

## Sound

All sound effects are synthesized at runtime with the Web Audio API (no audio files).
